# oops
 
Object Oriented Programming with C++ — a collection of practice programs exploring core OOP concepts and their implementation in C++.
 
## About
 
This repository is a learning resource for Object Oriented Programming (OOP) principles, implemented through small, focused C++ programs. It's aimed at students and anyone brushing up on OOP fundamentals.
 
## Topics Covered
 
- Classes & Objects
- Constructors & Destructors
- Encapsulation
- Inheritance (single, multiple, multilevel, hierarchical)
- Polymorphism (compile-time & run-time)
- Function & Operator Overloading
- Abstraction & Abstract Classes
- Virtual Functions
- Friend Functions & Classes

## Getting Started
 
### Prerequisites
 
- A C++ compiler (e.g., `g++`)
### Compiling & Running
 
Clone the repository:
 
```bash
git clone https://github.com/srushtiiisonvane/oops.git
cd oops
```
 
Compile an individual program with `g++`:
 
```bash
g++ oops/<filename>.cpp -o output
./output
```
